### **git log**
***
`git log` - просмотр истории коммитов в репозитории git  

**Пример вывода:**  
```
commit хеш
Author: автор
Date: 28.09.2050 01.30
    сообщение коммита 3

commit xeш
Author: автор
Date: 28.09.2040 01.30
    сообщение коммита 2

commit xeш
Author: автор
Date: 28.09.2030 01.30
    сообщение коммита 1
```

`git log --oneline` выводит коммит на одной строке, содержащей только его хеш и первую строку сообщения коммита  

`git log --graph` рисует ASCII-граф истории коммитов, показывая ветвления и слияния  

`git log --all` выводит все доступные коммиты в репозитории

### **git checkout**  
***
`git checkout` используется для переключения между ветками, восстановления файлов из индекса или рабочего каталога, а также создания новых веток.  

`git checkout -- <file_name.txt>` отмена изменений

`git checkout <хеш_коммита>` переключение на определенный коммит изменений

`git checkout <имя_ветки>` переключение между ветками

**Дополнительно**  
`git switch <имя_ветки>` переключение между ветками

`git switch -с <новая_ветка>` создание новой ветки и переключение на нее

`git switch <хеш_коммита>` переключение на определенный коммит

`git restore --staged <файл.txt>` восстановление файлов из индекса

`git restore <файл.txt>` восстановление файлов из предыдущего коммита

### **git branch**
***

`git branch` - список доступных веток в локальном репозитории  
`git branch -r` - для удаленных  
`git branch -a` - для всех (локальных и удаленных)

Пример вывода (звёздочка отмечает текущею ветку): 
```
* main
  origin/branch1
  origin/branch2
```

`git checkout <branch_name>` или `git switch <branch_name>` - переключение на существующую ветку с именем branch_name  

`git checkout -b <branch_name>` или `git switch -c <branch_name>` - создание новой ветки с именем branch_name и переключение на нее.

`git branch -d <branch_name>` - удаление ветки с именем branch_name (если она была полностью слита с другими ветками)  
`git branch -D <branch_name>` - удаление ветки с именем branch_name, даже если она не была полностью слита с другими ветками

`git branch -M <new_branch_name>` - переименовывает текущую ветку в new_branch_namе, если ветка с именем new_branch_naме уже существует, она будет перезаписана новыми данными без каких-либо дополнительных запросов или подтверждений.  
`git branch -m <new_branch_name>` - переименовывает
текущую ветку в new_branch_name. Если ветка с таким именем уже существует, она не будет перезаписана, и в этом случае будет выдано сообщение об ошибке.

### **git merge**
***

`git merge` - используется для объединения изменений из одной ветки в другую. Обычно это делается для включения изменений из одной ветки (исходной) в текущую ветку (целевую).
1. `git checkout <master>` - для перехода к центральной ветке
2. `git merge <feature_branch>` - слияние с feature_branch
3. `git commit -m "Merge №1"` - подтверждаем изменения
