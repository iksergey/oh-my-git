# Отзыв: необходимость отдельного курса по Git 😁

Хочу отметить, что модуль по Git заслуживает отдельного внимания и считаю он должен быть оформлен как самостоятельный проект!  

На практике сталкиваюсь с тем, что многие программисты, даже опытные, либо слабо ориентируются в системе контроля версий, либо используют её неэффективно. В результате возникают потери истории, ошибки при слияниях, хаос в ветках и другие проблемы, которые легко предотвратить при правильной работе с Git и GitHub.

Ведь в нашей работе с git - это не просто инструмент, а основа командной разработки. Умение правильно ветвиться, коммитить, откатываться, разрешать конфликты, использовать rebase, stash и pull requests.

Модуль очень хорошо структурирован! Поэтому, очень бы хотелось, чтобы с ним познакомилось, как можно больше людей (даже те, кто уже давно в профессии... не помешало бы освежить свои знания)!
